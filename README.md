# Plainly Medicine — Complete Site Update

This ZIP contains the complete site and preserves the existing visual design,
article text, detailed inline SVG illustrations, interactives, colors, and
section spacing.

## Included improvements

- Mobile section menus scroll within the viewport.
- Mobile navigation closes with Escape, outside taps, and desktop resizing.
- Clear keyboard focus states.
- Social sharing preview image and metadata.
- Current-page highlighting in the All Sections menu.
- Previous and next article navigation across all eleven pieces.
- Rewritten About this project section.
- All reader settings:
  - Appearance: Light / Dark / System
  - Text size: Small / Default / Large
  - Reading width: Narrow / Default / Wide
  - Line spacing: Compact / Default / Relaxed
  - Article font: Sans / Serif
  - Higher contrast
  - Reduce motion
  - Underline links
  - Reading progress
  - Sticky article contents

Settings are stored locally in the visitor's browser and apply across pages.
Reading width, line spacing, article font, reading progress, and sticky contents
affect article pages without redesigning the homepage.
