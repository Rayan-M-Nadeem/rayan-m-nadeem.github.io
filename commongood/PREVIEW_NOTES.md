# Private owner dashboard

The combined CommonGood directory is restricted to the owner's verified account. The former hub URL redirects to its protected sign-in. This public repository does not contain the current directory or the links it lists.

Organization teams receive only their own independent website URL. Each site has a separate membership list and Public/Private setting. Existing organization-specific bookmark routes continue to redirect only to their own site.

Live access controls cannot recall earlier downloads, external copies or repository history.
